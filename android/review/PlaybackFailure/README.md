# 播放失败自动续播验收

Android 0.1.59（versionCode 60）：播放器重试预算用尽后记录当前曲目错误并自动继续；下首预加载失败后寻找后继，当前曲自然结束时直接交接，保留原始队列。尊重实际随机顺序和暂停操作，单曲循环不困住失败恢复，全部失败停止，明确重试或选曲重新尝试。

- 198 项 JVM 回归、Lint、完整 APK 与测试 APK 构建通过。
- API 36.1 模拟器上 4 项设备回归通过：当前失败自动续播、坏下首不打断当前曲并跳到可播后继、单曲循环下全部失败有界停止并可重新选曲、原有媒体按钮与队尾自动停止。
- Media3 在自然切换前仍可能等待无效后继的缓冲；已知下首失败时在当前曲结尾接管交接，设备回归确认当前曲继续播放、队列未丢失。
- 异步预加载失败通知、后继准备和取消后迟到失败的 JVM 回归通过。

验证使用独立通用插件夹具与本地 WAV，不包含用户账号或内置平台实现；未覆盖真实 Android 手机及所有第三方音源。
