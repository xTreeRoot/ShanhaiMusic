# 安卓组件与应用更新验收

参考用户提供的 XRadiant 3.7.6 公开首页和登录页，统一灰白/深色分组、圆角输入、蓝色主操作、大标题与黑色选中导航。未登录参考应用，也未复用其代码或资源。

组件层位于 `ui/components`，覆盖按钮、图标按钮、输入、列表、开关、复选框、滑杆、筛选、菜单、弹窗、底部面板、顶栏、标签及宽屏导航项。所有业务页面迁入同一层，文本、图标、布局、系统 WebView 和媒体输出继续复用原生实现及统一主题。

设置的“检查版本”从山海官方 GitHub Releases 筛选安卓正式版本，按数字比较；下载可取消，逐块核对大小和 SHA-256，读取 APK 核对包名、版本与当前签名，最后通过系统安装器确认覆盖。未知来源未授权时打开本应用授权页，返回后再次点安装。

验证：153 项 JVM 测试通过；lint 0 错误、33 项警告；release/debug/测试 APK 构建通过。组件操作、更新动作、双行音乐发现、视频封面及歌单创建/改名/删除连续 5 轮，共 25 项通过。账号页登录、导航和退出确认另连续 5 轮通过；验证了系统音量与歌曲操作面板。Android 9 的瞬时弹窗关闭后 activeWindow 可能为空，测试改为从应用窗口列表定位，不重试业务操作。最终补测更新检查失败不得显示“已是最新版本”，并从错误状态完整走通检查、下载、取消和安装交接，连续 5 轮通过。
