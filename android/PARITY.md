# 与 iOS 的功能对照

基础对照为 iOS 0.1.0 Build 17（`6cdfb5d`，`mb-ios-v0.1.0` 标签）。安卓 0.1.1 预览版部分跟进 Build 18（`65078a7`）的布局与系统歌词，系统 OAuth 尚未移植。此表区分已实现、已实测和待验收；APK 可构建不等于已经齐平。

0.1.1 重新设计发现页推荐封面、曲目列表、手机底栏、迷你播放器和全屏播放页。发现页音源放在工具栏下方独立横滑的一行。

## 0.1.4 预览版

- 发现、搜索、插件目录、个人内容、下载、歌单和本地资料库不再因控制器尚未连接而禁用可播曲目。点歌直接走已有的连接和重连路径，不需要先点「重新连接」；不可播曲目和过期音源的搜索结果仍不能选。当前队列的传输控制仍要求连接。
- Android 16 无窗口以同一测试点资料库中的本地 WAV：先让服务不可用，再恢复服务，只点歌曲、不点「重新连接」。0.1.3 没有开始播放，修复后连续 5 次进入播放且进度前进，完整设备回归 46 项通过。报障真机、真实账号及 Android Auto 未验收。

## 0.1.3 预览版

- 对齐 iOS Build 23 的插件登录诊断：完成、失败或取消时保存最近一次报告；只记录已授权的脚本请求，最多 32 条，不保存原始 URL、Cookie、账号或错误消息，也不进入可携带备份。Android 16 无窗口回归覆盖截断、脱敏、浏览不更新报告、超时及取消。
- 对齐 iOS Build 23 的视频错误恢复：视频地址失败或视频读取终止时解除音频等待，保留曲目和播放或暂停意图；拖动音频不会重新请求已失败的视频，可手动重试。旧包复现两种错误都卡住健康音频，修复后两项无窗口回归各连续通过 5 次。报障真机仍未复测。
- 连续播放约每 30 秒安排一次播放进度备份，不再只更新应用私有队列。Android 16 无窗口独立测试包对照：旧包播放 36 秒后外部位置仍为 0；新版自动备份到 `30674 ms`。删除原导入文件、卸载并重装后，重选原目录恢复逐字节一致的音频，队列停在 `30674 ms`，手动播放从同一位置继续。
- 发布 APK 通过 45 项 Android 16 无窗口设备回归及 119 项 JVM 回归；Lint 0 错误、29 警告。与 0.1.2 的签名证书相同，APK 和 64 位原生库通过 16 KiB 对齐检查。

- 对照 iOS CarPlay 的系统媒体会话路径，不声明独立车机应用。Android 16 无窗口实测：屏幕进入 `Asleep` 后真实 B 站游客流继续播放，系统媒体键可暂停、继续、下一首和上一首，活动队列索引由 0 到 3 再回 0。这个验证不代表 Android Auto 发现或真车显示已通过。
- 对照 iOS Build 23（`8c6522c`）的搜索首页：输入栏下方显示音乐/视频分段（仅在视频模式且音源支持时）；最近搜索自动换行；内置音源提供四个浏览音乐入口，复用发现页的分类加载与返回路径；插件提供搜索音源入口。Android 16 无窗口验证真实 B 站游客搜索、历史回填、音乐榜打开与返回；用合成插件验证联想去重和提交、视频检索、切回音乐、进入分类搜索及返回。窄屏（320 dp）深色和 2.0 字号下核对布局及同排卡片高度。截图：`android-search-browse-light.png`、`android-search-narrow-dark-categories.png`、`android-search-plugin-scopes.png`。
- 播到 70% 后，按自动播放顺序只准备下一首的地址与首个 256 KiB，短曲最多读到结尾。预备数据只在内存保留 90 秒，不创建播放器、不进入备份。暂停、退回阈值、调整队列、随机、循环、音质或进入视频会取消；续传未通过同一流的校验时丢弃首块，从头正常读取。HTTP 夹具覆盖范围、过期和取消；无窗口 ExoPlayer 夹具确认可复用首块解码并跳到后半段继续播放。
- 插件 `fetch` 支持 `follow`、`manual` 和 `error`。`manual` 将 3xx、`Location` 和独立的 `Set-Cookie` 项交给插件，不替插件跳转；自动跳转仍检查每跳权限。已测合成响应，未完成汽水实际扫码授权。
- 插件网页登录优先使用 WebView 独立配置；兼容路径在独立进程创建专用目录，不读取默认浏览器 Cookie。Android 15 / WebView 124 与 Android 16 / WebView 134 无窗口设备回归覆盖兼容路径，尚未覆盖报错真机。
