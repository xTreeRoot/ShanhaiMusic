# 山海 Android · 万端归一

0.1.58 的插件管理新增「已安装 / 社区」、山海维护 Stars 列表内搜索和分页安装、包内图标和作者头像，安装后返回已安装并定位高亮。验收记录见 [插件中心](review/PluginCenter/README.md)。

山海是跨平台内容入口，标语为「万端归一」。支持覆盖更新并保留账号、插件与资料库。

安卓客户端在 `android` 分支的 `android/` 目录维护。当前版本号以 `app/build.gradle.kts` 为准；覆盖更新沿用原签名。已实现、已实测和待补项见 [PARITY.md](PARITY.md)。

## 终端构建

需要 JDK 17、Android SDK Platform 36.1、Build-Tools 36.1.0、NDK `28.2.13676358` 和 CMake `3.22.1`。应用最低支持 Android 8.0（API 26）。

```sh
export ANDROID_HOME="$HOME/Library/Android/sdk"
export JAVA_HOME=$(/usr/libexec/java_home -v 17)
cd android
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

Debug APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。以上命令不会启动 IDE 或模拟器。显式执行设备测试时，只用独立的无窗口模拟器或用户指定的设备；不复用手机端生产账号。

原生音频与 QuickJS 宿主测试需另构建 `:app:assembleDebugAndroidTest`。把两个 APK 安装到专用的干净测试设备或模拟器用户后，用 `adb -s <测试设备序列号> shell am instrument -w com.xtreeroot.mb.test/androidx.test.runner.AndroidJUnitRunner` 运行。播放回归需要初始队列为空。默认测试使用生成的 PCM 波形和固定插件响应，不要求联网或账号。

可选游客实网测试：只在干净的测试用户中把校验过的插件 ZIP 放入调试 App 的 `cache/guest-playback.zip`，运行 `adb -s <测试设备序列号> shell am instrument --user <测试用户ID> -w -e class com.xtreeroot.mb.playback.GuestPlaybackDeviceTest -e guestPlugin <netease|ximalaya|soda> com.xtreeroot.mb.test/androidx.test.runner.AndroidJUnitRunner`。预期插件版本见测试中的 `releases`。该测试不登录，验证实际起播和拖动；游客权限、曲目可用性与平台网络都会影响结果，不纳入默认回归。

## 覆盖安装与数据保护

真实手机禁止使用 ADB 增量安装（`--incremental`）；不稳定的无线连接会触发系统数据加载失败并卸载包。优先将完整 APK 传至手机，核对 SHA-256 后调用系统本地安装器覆盖。确需 ADB 安装时必须显式 `adb -s <设备> install --no-incremental -r <APK>`，先核对包名、原签名和版本号。不得通过卸载、清除数据或自动化测试解决安装问题。

覆盖前保留独立数据备份并核对；具备已授权调试读取能力时，备份范围必须包含 `files`、`shared_prefs` 和 `databases`。只有文件备份时，不得宣称已恢复 SQLite 内全部资料。真机覆盖后核对首次安装时间保持不变，并由用户核对资料库、下载、插件名称与排序。所有会重置数据的 Instrumentation 测试只能运行于专用模拟器。

## 卸载后保留资料库

导入和下载的歌曲都能从本地资料库播放；缓存不算入库。播放页的 **本地喜欢** 独立于平台点赞。移除或停用音源插件不影响已下载音频。

已导入或下载的曲目可从曲目操作里「分享音频」，也可用「导出音频」另存。分享交给 Android 系统选择接收方，临时副本不进入资料库备份。

资料库下拉可刷新本地曲目和已保存列表，不清空搜索条件。正在下载的曲目在资料库首页显示，点曲目旁的关闭按钮即可取消，不用退出搜索或进入「下载与缓存」。

点专辑或歌手可进入分组详情。分组和歌单里的 **播放全部**、**随机播放** 只会加入当前搜索命中的歌曲。同名专辑优先按专辑作者区分；没有专辑作者时，文件夹导入用目录摘要区分，单独选文件用曲目作者区分。备份不记录导入目录路径。

曲目列表标出当前歌曲，暂停时仍然保留标记。长按可播曲目打开操作面板，可插入下一首、加入队列或执行歌单、下载和导出等适用操作。

导入文件夹时，同目录的有效同名 `.lrc` 优先于内嵌歌词；无有效 LRC 时读取 MP3 或 M4A/MP4 的内嵌歌词。单独选音频时，Android 只授予该文件的访问权限，不能扫描同目录的 LRC；可以在曲目菜单手动附加。

在 **资料库 → 数据位置** 中选择一个独立于 App 的本机文件夹，例如 `Documents/MB`。山海在所选文件夹下创建 `MB Data`，页面显示选中的文件夹名和最近备份时间。增量备份包含已导入和下载的音频、歌单、喜欢、最近播放记录、本地歌词、搜索历史、播放队列、自定义背景、非敏感设置和已安装的插件包。插件只备份安装文件和预设选项，不备份启用状态、密码、自由输入配置或 `host.storage`。APK、工作数据库、在线播放缓存和账号凭据不写进该目录。

连续播放时，应用约每 30 秒安排一次进度备份；暂停或切歌也会安排更新。恢复队列时不会自动播放，点播放后可从已备份位置继续。

卸载前点 **立即备份**，等备份完成并确认没有错误。手动备份按长度和 SHA-256 核对所需文件，即使长度没变也能发现损坏；本机原件仍在时会补写并读回校验。校验报错时先不要卸载。重装后进入同一页面，重新选择原先的文件夹（不是 `MB Data` 子目录）；Android 会要求重新授权。恢复前同样检查文件完整性，已有项目不被同 ID 的旧副本覆盖，已经设置的偏好不被旧备份覆盖。恢复的插件保持停用，请在插件详情核对权限后手动启用。没有选独立目录时，只存在 App 私有数据，卸载不会保留它。

## 外观与插件

- 各音源的个人目录和已加载分页按插件版本、账号、路由及游标缓存 6 小时，重新进入或重启后可复用；过期刷新失败时保留旧内容。下拉刷新和收藏、喜欢、歌单编辑会使列表缓存失效。缓存不包含媒体取流结果，不代替账号验证，也不会自动遍历尚未加载的分页。
- 个人资源的歌曲、歌单、专辑、作者、目录入口封面和头像共用 Coil 图片缓存，磁盘上限 256 MiB，按最近使用淘汰；已加载页面最多四路预取封面。即使图片服务器声明不缓存也保留本地副本，同一 URL 使用不同请求凭据时隔离缓存，锁屏与页面复用相同文件。
- 视频模式下，发现首页和分类详情按屏幕宽度排列横封面；封面右下角显示已知时长。听歌模式保留横滑精选和榜单。
- 视频详情的分段控件显示当前播放画面。切到听歌模式会打开同一曲目的播放器，不重排队列或重置进度；直接打开视频或返回浏览不改变已保存的模式偏好。歌词与字幕按当前句的实际高度居中，包括换行和译文。
- 手机播放页工具栏可以主动切换横屏和竖屏。全屏视频优先横屏，并隐藏系统栏；点画面显示控制条，可在顶部看到当前标题和退出键。离开后把方向交还给系统，平板和分屏不强制旋转。视频「队列」末尾可调手机的系统媒体音量，不改山海的应用音量。
- 播放页的画笔菜单可直接切换封面、黑胶、磁带和三种歌词舞台，不用退出播放器改设置。对支持视频的音源，可点封面或视频按钮打开当前曲目的视频，不改变全局浏览模式。
- 播放页的 **音频输出** 打开 Android 系统设备面板，不支持时提供蓝牙设置入口。**退出电台** 只停止追加电台曲目，当前歌曲和已入队曲目继续播放。
- Android Auto 媒体入口复用手机的播放队列；选中当前曲目可从原进度继续，空队列没有续播项。语音播放只匹配当前队列内的歌名和歌手，不访问插件目录或个人页面。实际车机连接尚未验收。
- 在 **设置 → 外观** 选择本机背景图。山海将图片降采样并另存为 PNG，删除原图不影响当前背景。连接独立数据目录后，只备份这份 PNG，不保存原图路径；重装恢复时不会覆盖已经设置的背景。可在同一处恢复默认背景。
- 在 **设置 → 插件** 点全部更新，优先使用最新发行中的 `plugin-universal.zip`，与桌面和 iOS 共用。没有该附件的旧仓库继续使用默认分支的固定提交归档；相同提交跳过，同版本号的新提交仍会更新。社区逐项安装沿用相同规则。只处理有 GitHub 来源的外部插件（含停用项）；安装包新增网络权限时仍需单独确认。插件更新保留原启用状态、设置和私有数据。删除插件需确认，只移除公开代码；信息源全部由独立插件提供。
- 插件网页登录优先使用独立进程和一次性数据目录。Android 9 及以上直接使用系统目录隔离能力；Android 8 使用当前 WebView 提供程序支持的隔离能力。独立进程无法启动时，可在支持独立配置的 WebView 上改用一次性配置；不会使用默认浏览器会话。没有可用的 WebView 时需在系统设置里启用提供程序。主页面网络错误或 HTTP 5xx 单独提示；图片或嵌入框架失败不结束会话。
- 信息源由外部插件提供。插件返回 HTTPS 备用媒体地址时，播放器可在打开前尝试备用地址；成功打开后锁定该地址，不在同一次流读取中拼接两条线路。
- 离线下载可跟随 HTTPS 跳转，跨域不转发原请求的私有请求头。下载同一音轨的备用地址时从头写入临时文件；下载完整才入库，失败或取消不会留下半首歌。
- 插件可在其 `signIn` 中调用 `host.oauthSignIn({authorizationEndpoint, tokenEndpoint, clientID, redirectURI, scopes})`。它打开系统浏览器，以 PKCE 和单次 `state` 换取 JSON 令牌，回跳须在服务端注册为 `com.xtreeroot.mb:/oauth2redirect`。需使用适配 Android 的客户端配置，不支持直接套用现有 YouTube 插件里的 iOS OAuth 客户端和回跳。
- 播放失败时，完整播放器会显示错误码；能够从异常类型识别时，附上 HTTP 状态、HTML 响应、DNS、TLS、连接失败或超时标记，不显示原始错误消息。系统拒绝音频焦点时，迷你和完整播放器会提示；可暂停占用音频的应用，再点播放，队列和进度不变。排查时可同时试播一首已导入的本地音频，区分本地播放与平台取流，不需要提供 Cookie 或带签名的媒体地址。
- 隔离网页登录提示附带错误码：`WV-01` 无可用提供程序、`WV-02` 不支持隔离、`WV-03` 启动失败、`WV-04` 页面加载失败、`WV-05` 网站暂时不可用、`WV-06` 渲染器退出。独立进程找不到提供程序时，主进程会尝试可用的独立配置，不共用普通 WebView 的 Cookie。
- 已授权的调试设备可在复现后运行 `adb -s <设备序列号> logcat -d -s MBPlayback:I MBPluginBrowser:I '*:S'`。这两个日志标签记录播放服务连接、播放错误码、WebView 提供程序和启动阶段，不记录曲目、请求地址、账号或 Cookie。
- 插件数据目录保留最近 24 次登录、验号、退出、清理登录缓存的 `account-diagnostics.json`，以及最近一次登录的 `sign-in-diagnostics.json`。复现后可对调试包执行 `adb -s <设备序列号> shell run-as com.xtreeroot.mb cat files/plugins/data/<插件ID>/account-diagnostics.json`。报告包含时间、插件版本、操作结果和插件存储读写计数；每次最多 32 条请求，记录耗时、域名、路径 SHA-256、HTTP 状态码、有界整数业务码或异常类型，以及请求是否声明 Cookie / Authorization 头、响应返回的 Set-Cookie 数量。不保存存储键值、原始路径、查询参数、请求头值、正文、Cookie 或账号信息，不上传节点、不进入可携带备份。平台没返回明确原因时，日志不能推断会话是过期、被撤销还是风控拦截。
- 听歌进度到 70% 时，山海会为自动播放的下一首先取地址和最多 256 KiB 音频，只临时放内存；下一首已有本地副本时不走网络，也不会提前播放。

## 模块

- `music`：音源与媒体、账号、资料库、互动合同。
- `plugin`：独立信息源的运行时、安装与通用能力桥接。旧宿主存储只读迁入对应插件的独立数据目录，保留旧文件和已有目标键。
- `plugin`：复用 iOS 的 QuickJS 源码与宿主脚本，通过 JNI 调用。提供 ESM、私有存储、兼容现有脚本的加密接口、可取消的异步请求、媒体请求头规则和隔离的 WebView 登录。支持 ZIP、目录、GitHub 暂存与确认；插件可提供登录、主页、目录、个人集合、分类搜索、音频、视频和歌词。
- `playback`：Media3 音频服务、系统媒体会话、队列与位置恢复。只持久保存曲目身份，不保存临时流地址。
- `local`：通过系统文件选择器导入并持有音频副本，按 SHA-256 去重，读取标签、内嵌封面和歌词；不修改原文件。
- `preferences`：偏好持久化和分域代理策略；代理名单不记录账户或凭据。
- `ui`：Compose 界面、请求状态与手机/宽屏导航。视频独立解码，不替换后台音频队列。

## 节点完整备份

“山海服务 → 设备设置”的“备份本机”提供端到端加密的完整备份，包含插件包、名称、开关、排序、完整设置和私有数据，以及资料库、下载、搜索历史、播放队列及 Android 偏好。接入同一节点后点“从其他机器恢复”，选择源设备并恢复，即可向空白客户端补装插件和还原资料。已有插件代码和私有文件保留，队列仅在本机为空时暂停恢复；跨平台只应用支持的通用偏好。节点身份和令牌不迁移，旧备份继续按仅设置恢复。需要节点 0.1.3；平台可能要求重新登录。此功能包含插件登录数据，与“资料库 → 数据位置”的公开目录备份范围不同。
