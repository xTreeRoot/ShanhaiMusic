# 平台喜欢与添加歌单回归

插件/App 喜欢状态相关行为与平台菜单 UI 连续运行 5 次通过；账号切换、失败重试、过期状态、迟到列表与只读红心均有回归。全量 Go、插件测试与 MyGo vet 通过。截图使用隔离 source，不能当作真实平台账号写入验收。

播放器“更多”可选择插件本人普通歌单；固定系统列表仅在声明 addable 时可选，写操作仍使用原始来源和曲目 ID。

桌面补查：底部播放条、普通曲目行、待播清单、每日推荐、播客、视频卡片、封面墙和紧凑播放器提供直接操作入口。曲目行及待播/每日推荐/播客/视频卡片的操作动作连续运行 5 次，确认打开菜单与复制不会启动播放。B 站收藏夹的固定列表可单独开放原生移除；喜欢页使用明确取消喜欢，不按旧图标反向切换。
