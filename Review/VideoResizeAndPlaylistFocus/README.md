# 视频窗口与歌单当前曲目定位

桌面 0.1.43 修复视频模式立即作用于当前曲目，播放栏按钮按当前模式打开播放器，快速切换模式不再误关窗口。视频窗口最小尺寸降至 160×90，macOS 使用 AppKit 原生窗口比例约束，解码后按实际视频宽高更新，支持竖屏；小窗自动切换紧凑控制层。

打开歌单时按音源和曲目 ID 定位当前播放或暂停的曲目；分页沿用原有接口查找，远距离直接接近目标后平滑滚动最后两行，手动滚动停止定位。不会重启、跳歌或改变进度。

相关离屏 UI 与隐藏 AppKit 比例测试连续 5 轮通过，全量 Go、插件测试、MyGo vet 通过。前序视频模式真实原生窗口回归通过；后续验证未显示窗口。未验证真实平台账号取流。
