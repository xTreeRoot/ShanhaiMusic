# 歌单自动定位当前曲目

build 73 在打开平台或本地歌单时定位播放器当前曲目，播放与暂停均适用，使用来源和曲目 ID 匹配。列表只定位一次，分页查找复用现有加载入口，原生滚动动画约 260ms，系统减少动态效果时立即定位；手动拖动及离开页面取消定位。

272 项 Swift Testing 与 4 项 XCTest 行为测试通过，SwiftUI 公共模块编译通过。iPhone 18 Pro、iPad Pro 13-inch (M5) 的本地与平台歌单共 4 项 UI 回归通过，目标均为长列表第 36 项；本地测试还验证手动滚动后不被拉回。全部使用独立演示数据，没有向真实账号写入。

截图及测试来源见 [截图索引](SCREENSHOTS.md) 和 manifest.json。公开 IPA 必须未签名；真机签名构建沿用既有团队，并覆盖安装保留数据。
