# 山海服务入口和节点表单

入口位于“我的”的“插件”下方，使用同组列表样式；桌面位于侧栏插件入口下方。设置内旧入口移除。节点接入表单参考 Ant Design Mobile 的分组、左侧标签与右侧输入、清空、密码显隐及整行主按钮，保留既有原生组件和主题。

## 验证

- iOS：清空、密码显隐、非法 HTTP 地址不得接入或改写原绑定，连续五轮通过；iPhone/iPad 共用界面编译通过。
- 桌面：清空、显隐与原节点操作回归连续五轮通过；插件测试、Go 全量测试、MyGo vet 和 macOS arm64 打包通过。
- 服务器：资料接口的鉴权、加密跨端读写、空间隔离、ETag 冲突、墓碑与撤销授权已通过公开 HTTPS 地址的合成设备测试。升级前已备份数据库与程序；既有数据的行数及内容摘要保持一致。
- Android：构建及节点单元测试通过；清空、显隐、非法 HTTP 地址不接入且保留原绑定的设备交互连续五轮通过。

本次表单未使用用户真实账号进行登录、扫码或改写资料；线上探针记录与授权已清理。插件偏好新增合同与行为回归见 `server/EDGE.md` 及三端 `PluginPreferences` 测试。

插件偏好新增行为回归：Go 文档/本地双份缓存/节点同步 `-race` 通过；Swift 两项文档及节点同步测试通过；Android 三项文档及节点同步测试通过。验证了远端恢复、名称清空墓碑、未知插件 ID 保留、并发独立修改、ETag 冲突重读、损坏数据拒绝及节点切换取消。`app/plugins` 线上 HTTPS 合成探针也通过跨端读写、空间隔离和墓碑校验。
