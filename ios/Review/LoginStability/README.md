# 插件与播放稳定性修复

产品版本 0.1.0。build 7 修复宿主提示与封面崩溃；build 8 增加不含凭据的登录诊断；build 9 合并 `2117da1` 的新页面与播放模式切换，并配合兼容插件 0.1.15 修复切换 App 后的扫码断连。

## 定位结果

- 手机安装的是 `sogud/mygo-music-netease v0.1.14`。入口已和上游提交 `7b8cb7a7203170afbfee5cb132e34624f69013c4` 逐字节比对一致，未读取账号存储。纯文字提示与后台封面崩溃属于宿主问题；后续扫码确认后的断连另有插件原因，见下文。
- 原版插件在二维码生成前调用 `host.signInPrompt({text: ...})`，登录完成后也只传文字。桌面合同允许省略 `qr`，iOS 宿主却强制要求 URL，在发出请求前就抛出 `Invalid sign-in prompt`。
- 手机 build 4 的崩溃报告显示 `EXC_BREAKPOINT / SIGTRAP`，触发线程是 MediaPlayer 的 `accessQueue`，堆栈指向 `SystemPlaybackCoordinator.update()` 创建的封面回调。回调隐式继承 MainActor，系统从后台请求图片时触发隔离断言。重启恢复同一曲目的封面会再次触发。

## 修复

登录提示使用可选二维码 URL；无二维码时显示进度和平台文字，提供地址时继续校验。封面回调显式为 `@Sendable`，只捕获解码后的图片，不访问主线程播放状态。系统媒体命令回调也显式为 `@Sendable`，在 Task 中回 MainActor 执行业务。

## 扫码确认后的断连（build 9 / 插件 0.1.15）

用户在网易云确认登录后切回山海，build 8 的单次诊断记录显示二维码生成与前两次轮询均 HTTP 200，下一次轮询返回 `NSURLError -1005`。原版插件将传输失败直接结束为“无法读取网易云音乐”。诊断文件仅保存域名、路径摘要、HTTP 状态与系统错误码，不保存路径原文、查询参数、请求头、响应内容或账号。

按用户要求建立 [xTreeRoot/mygo-music-netease](https://github.com/xTreeRoot/mygo-music-netease) fork，提交 `fa05e60`，版本 0.1.15。仅对同一二维码的状态轮询与确认后的账号读取增加两次传输重试，等待 500 / 1500 毫秒，保留待确认 Cookie。每次请求前后检查登录代次与 3 分钟期限；业务拒绝、HTTP 错误、响应解析错误和二维码过期不重试。点赞等写操作不增加重放。

- Node 全量 52 项测试通过，覆盖轮询/账号读取断连、请求超时、重试上限、取消、登录过期、二维码过期与写操作不重放。
- Swift 全量 138 项回归通过，真实 QuickJS 宿主注入两次 `URLError.networkConnectionLost` 后使用原二维码完成登录，保存并恢复虚构会话。
- 原版 0.1.14 与修复版 0.1.15 的公开源码夹具独立保留，包含许可证和来源。
- 用户安装后已明确反馈“登录成功”；手机仅含状态的诊断显示两次 -1005 均恢复，最终 completed 为 true。未读取账号 Cookie。

## YouTube 和汽水插件适配

- 原 YouTube Music 插件依赖 `host.spawn`、ffmpeg、yt-dlp 与本机 HTTP 转码；iOS 不提供这些进程能力。fork [xTreeRoot/mygo-music-youtube-music](https://github.com/xTreeRoot/mygo-music-youtube-music)，提交 `e619388`、版本 0.1.2，沿用上游 VISIONOS player 合同选择 AAC/MP4 直链，交给 AVFoundation。3 项 Node 回归及真实 QuickJS 合同通过。开发机启用代理后，真实首页、搜索、取流、完整音频下载、可播放性与时长检查通过；Google 登录与手机实际听音未验收。
- 汽水完整版候选依赖官方桌面签名 SDK、原生 helper 与加密媒体处理，其桌面组件不能直接运行在 iOS。选择公开内容的 MIT 插件 fork [xTreeRoot/mygo-music-soda](https://github.com/xTreeRoot/mygo-music-soda)，提交 `5d0db9b`、版本 0.2.1，移除未验收的实验登录并返回实际 AAC 音质。4 项 Node 回归、真实 QuickJS 首页与取流、完整下载及 AVFoundation 可播放性通过。部分歌曲只提供试听或没有可用 AAC，会正常反馈不可播放；不宣称搜索、私人歌单或会员支持。

所有真实音频检查不加载手机账号存储，不保存或提交签名媒体地址。构建和设备日志位于忽略的 `.build/`；本版源码指纹见 `build12-sources.sha256`。

最终本地全量 Swift 回归为 148 项通过；包含新增清除期间迟到的磁盘恢复保护。YouTube 0.1.2 与汽水 0.2.1 已无线复制安装，更新源分别指向本人的 fork。


## build 14 补充与安装事故
