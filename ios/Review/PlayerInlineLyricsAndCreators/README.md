# 音乐播放器紧凑歌词、图标操作与作者主页

Android 0.1.43（44）、iOS 0.1.0（45）。

## 改动

- iOS 与 Android 限制封面舞台高度，歌名、歌手与右侧点赞、评论、更多随之上移。封面舞台适度下移；封面下方仅显示两行可滚动的紧凑歌词，当前句跟随到第一行；点击大封面仍进入完整歌词，点顶部小封面返回原样式。
- 移除随机、循环、歌词、音频输出、待播清单图标旁的常驻文字，保留可访问名称。操作显示短暂轻提示，随机与循环显示实际切换后的模式。
- 紧凑歌词保留独立确认：先选择某句，再点右侧播放标识才定位，不改变双击或滚动时的播放位置。
- 作者入口根据当前插件真实导出的 `artist` 能力启用；插件无此能力或曲目没有作者 ID 时显示普通歌手名称。App 仅调用通用目录协议，所有平台接口保留在独立插件。

## 独立插件

- 哔哩哔哩 1.1.4：补齐作者目录、作者资料与作品分页，复用插件现有官网访客上下文。作品请求受平台限制时保留真实作者资料并给出刷新反馈。
- 网易云音乐 0.1.20：作者附加专辑请求失败不再拖垮整页，保留歌手资料和歌曲。
- QQ 音乐 0.3.11：作者歌曲 offset 正确传给分页接口，按总数继续加载；专辑失败不影响作者与歌曲。
- YouTube 0.2.9：官方频道与匿名网页分支均返回作者名称、头像和简介。
- 汽水音乐 0.4.3：补齐作者、歌曲与专辑目录，游标按账号代次隔离，复用已验证 PC 接口合同。
- 喜马拉雅 0.1.9：补齐主播资料、作品与专辑目录，以及触底分页和字符串时长转换。
- 波点音乐现有 0.3.6 的作者接口匿名实测正常，无需重复发布。

提交、发布资产摘要见 [插件发布记录](plugin-releases.json)。

- Swift 全量 223 项与 Android JVM 168 项通过；Android Release lint 0 errors、41 项既有 warning。iPhone/iPad 通用 Release、Android Debug/Release/AndroidTest 构建通过。
- Go 全量、插件宿主测试及 MyGo vet 通过。未修改桌面 UI 或桌面包。
- 两端紧凑歌词、歌词独立确认及封面往返连续五轮通过；iPhone 图标操作、模式轻提示与队列交互连续五轮通过，iPad 同项通过。最终截图与额外操作核对见 [索引](SCREENSHOTS.md)。
- 独立插件 Node 测试和语法检查通过。QQ、网易云、喜马拉雅与波点的公开作者请求已实测；QQ 与喜马拉雅续页返回不同数据。哔哩哔哩匿名作品请求受到 HTTP 412 限制，已验证保留资料的降级路径。汽水与 YouTube 的真实登录账号作者页未逐项验收。
