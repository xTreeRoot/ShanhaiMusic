# 播放失败自动续播验收

iOS 0.1.0 build 68：加载、地址刷新用尽或播放中断后自动寻找可播后继；下一首预加载失败后继续预加载，成功资源交接给播放器。保留队列及失败原因，遵循随机顺序；全部失败停止，显式选曲可重试，用户暂停不会被失败回调重新启动。

- 266 项 Swift 行为回归通过，包含连续失败、单曲循环、随机顺序、首块失败、成功交接、整队失败和暂停场景。
- iPhone 18 Pro 与 iPad Pro 13-inch (M5) 各通过自动跳过失败曲目、手动滑动切歌 2 项 UI 回归，共 4 次。
- 使用真实 NativeAudioEngine 与通用静音 WAV；测试夹具只在 Debug 显式启用，不进入公开 Release。
- 截图已人工检查，索引见 [screenshots.json](screenshots.json)。完整结果位于本工作树 `ios/.build/review/PlaybackFailureFinal.xcresult`。

早期 UI 用例错误地尝试点击演示模式的禁用播放按钮，并把歌名限制在不包含元数据的控件内；现已修正测试入口和定位，最终四次回归全部通过。未使用真实账号逐个验证第三方音源。
