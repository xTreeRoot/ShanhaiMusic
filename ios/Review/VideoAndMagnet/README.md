# 竖屏、磁力链、播放器与外部插件验收

2026-11-21，iOS 0.1.0 Build 29、Android 0.1.28（29）、桌面 0.1.14。三端在 main 维护。与本次验收对应的关键源码、截图及发行包 SHA-256 见 [verification.json](verification.json)。

## 行为

- iOS、Android 点击资源时主动展开对应的音乐或视频播放器；自动续播、恢复和播放/暂停不额外打开页面。
- 视频依据元数据和解码后的实际尺寸自适应。竖屏提供上下切换队列、评论、收藏、分享、字幕及加入歌单入口。听歌时后台准备同一视频，打开画面时复用；真实网络的首帧延迟和音画偏差仍需持续验证。
- 磁力链直接识别 btih（40 位十六进制或 32 位 Base32）及 btmh，作为链接资源保存或分享，不再当关键词提交搜索。关键词搜索委托已安装的资源搜索插件；App 不含 BT 下载、做种或解码引擎。
- 最近搜索可逐条删除或全部清除。
- 三端不再内置远程平台实现。插件账号、资料库和设置保留，已有会话通过通用存储迁移；iOS 恢复设置完成前不会以默认设置覆盖磁盘文件。

## 验证

- Swift 行为回归 179 项通过，串行与默认并行均通过；iPhone/iPad Release 通用构建通过。
- iPhone、iPad 模拟器：磁力链与历史删除、竖屏手势与互动入口两项各连续 5 轮通过；点击音乐自动展开播放器各连续 5 轮通过。
- Android JVM 147 项通过，Release Lint 为 0 错误、35 警告。九项设备专项连续 5 轮通过，覆盖大响应、死循环中断、竖屏实际解码及预载复用、互动入口、磁力链、历史删除、旧会话迁移、插件账号和自动展开播放器。
- Android 发行包经原证书签名、16 KiB 对齐检查；包名、versionCode、非调试状态和包内图标与源码一致性通过核对，无临时安装辅助入口。
- 桌面插件回归、Go 全量、MyGo vet、macOS arm64 打包及签名检查通过。网站图标在独立源码副本中使用 Node 24 完成 client/SSR 构建和 8 页预渲染。

- [YouTube 0.2.0](https://github.com/xTreeRoot/mygo-music-youtube-music/releases/tag/v0.2.0)：普通视频首页、Shorts、音乐分类、公开评论与字幕；27 项离线测试及公开接口实网检查通过。小米使用既有账号验证首页、Shorts、New Releases、音乐视频、评论和字幕读取。写评论、真实点赞和全部私人列表操作未由用户逐项验收。
- [Knaben 1.0.0](https://github.com/xTreeRoot/mygo-resource-knaben/releases/tag/v1.0.0)：独立资源搜索插件，2 项离线测试及公开搜索通过，小米实测关键词返回资源。
- 两台手机的上述三个插件公开代码和来源提交均已更新并读回核对；账号、名称、停用状态及独立数据目录保留。其余 iPhone 插件的版本和远端提交已核对为当前最新。
- 小米已通过 Wi-Fi 用原签名覆盖安装正式 0.1.28 并启动，未卸载或清数据。
- iPhone 15 重新上线后，已通过 Wi-Fi 覆盖含最终图标的签名 Build 29 并成功启动。安装前后 69 个数据文件的 SHA-256 全部相同；启动后逐项比较 JSON 语义及其他文件，设置、资料库、插件账号与排序均未变化，进程持续运行。当前选择的平台保留为更新前的值；已移除的内置来源开关不再写入新设置。哔哩哔哩旧会话与迁移后的 session 一致，三个更新插件的公开文件均与发布版逐一相同。
- 公开 iOS IPA 为未签名包，安装前需使用自己的 Apple 签名；真机使用本机个人团队签名包。
