# iOS 账号退出与显式登录缓存清理

iOS 0.1.0 Build 46；汽水音乐独立插件 0.4.4。

“我的”页在“退出登录”右侧新增“退出并清理缓存”，只为实际导出 `signOutAndClearCache()` 的来源显示。普通退出继续停用并保留会话；新按钮取消登录，清除当前插件的账号 Cookie、匿名设备注册与内存解析/歌词/目录游标，下次登录重新扫码。iOS 同时失效该插件目录响应缓存并重建两个执行通道，拒绝迟到账号响应。未清理插件设置、资料库、下载或其他来源数据。安装只更新 App 和插件公开代码，未替用户点击退出或清理。

App 使用通用 `AccountCacheResetSource` 协议，不读取平台存储键或调用汽水私有接口。平台状态清理位于独立插件，登录 WebKit 本身使用临时数据存储；不清全局浏览器 Cookie，也不使用系统钥匙串。

## 会员问题范围

当前汽水取流使用公开网页接口，未实现会员专属取流。这次按用户要求提供重新扫码入口，没有把会员无法播放标记为已修复。真实会员歌曲与重新扫码由用户后续验收。

## 验证

Swift 全量 225 项通过；汽水插件 31 项 Node 测试及语法检查通过。行为覆盖普通退出保留会话、显式清理后重新扫码、设置保留、迟到账号不会恢复、目录响应缓存失效及两条运行通道重建。iPhone 操作回归连续五轮通过，iPad 同项通过；iPhone/iPad 通用 Release 构建通过。
