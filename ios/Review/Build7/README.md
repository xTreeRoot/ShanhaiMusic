# Build 7 页面与交互验收

版本 0.1.0（7），2026-11-18 至 19 日。设计参考和逐页范围见 [DESIGN.md](DESIGN.md)，图片可在 [图库](index.html) 筛选，编号与原图见 [SCREENSHOTS.md](SCREENSHOTS.md)。

## 本轮改动

- 四个主入口为发现、搜索、资料库、我的；设置与插件从我的进入。参考 Apple Music、网易云音乐官方手机截图梳理封面、内容分区、歌单、评论和播放控制层级。
- 迷你播放器与底部导航分开，平板限制宽度居中；我的列表尾部可滚动到播放器上方，退出登录不会被遮挡。
- 歌曲内选择封面/黑胶/磁带立即显示对应舞台，选择 Flow/Steps/Tilt 立即显示歌词；重复选择当前样式同样切换舞台。手机点击封面直接打开当前曲目实时视频。
- 听歌/视频切换不重选歌曲、不重新加载音频，保留进度和暂停状态。视频支持加载、取消、重试、全屏与恢复浏览；异步保存不拖慢画面，最终落盘按最后选择。
- 修复真实游客启动/恢复曲目后，系统在后台请求锁屏封面导致的 Swift 6 actor 崩溃；系统图片回调不捕获主线程业务状态，远程命令显式跨回主线程。

## 验证与证据

127 项 Swift 行为回归通过（Foundation 100 + B 站 27）；公共 SwiftUI 宿主编译、iPhone/iPad 模拟器工程编译、通用 arm64 Release 构建通过。新增音视频反复切换、慢保存、能力恢复重试，以及系统后台取封面回归。

真实游客探针：首页四区各 6 条，更多页 30/20/100/40 条；搜索“夜曲”17 条，音频解码 4096 PCM 帧；视频 HTTP 206 分段加载与原生画面输出通过。封面探针因平台分区偶发错误获得三个分区，18 张 HTTPS 图片全部下载解码；真实首页保留失败分区并允许重试。

按设备/方法去重，iPhone 13 项、iPad 4 项 UI 回归通过，分批执行；方法与最后通过结果包记录在 [ui-validation.json](ui-validation.json)。手机最终 4 项覆盖账号/评论/发现、底栏、封面/歌词舞台即时展示和固定控制；音视频综合流程在 `Build7FinalRepairs.xcresult` 两项均通过。平板覆盖横竖屏、底栏、控制与样式。iPhone 另用暗色与 accessibility-large 验证滚动和操作可达，模拟器设置已恢复普通字体与浅色。

演示图库共 148 张，均来自通过的方法；截图不代表真实账号发布操作。真实游客 iPad 另有 1 项通过，音频实际开始播放后暂停，点击封面进入视频、切回听歌、再进视频；两次均等待缓冲结束与 AVPlayerLayer 实际帧就绪，最后保持暂停。5 张联网图片单独保留在 [live](live/README.md)，不混入演示图库。

系统音频会话仍有 Xcode 的同步 activate/deactivate 性能提示；本轮没有测量真机延迟与功耗，保留在未验收边界，不将无崩溃当作性能结论。
