# Build 7 页面与交互重构

## 真实参考（2026-11-18）

- Apple Music iPhone 官方 App Store 截图，版本 3.18：https://apps.apple.com/us/app/apple-music/id1108187390
  - 首页横向编辑推荐、清楚的分区、封面主导；迷你播放器位于导航之上。
  - 播放页以封面/歌词为中心，标题和播放控制层次清晰；歌词切换不切断控制。
- 网易云音乐 iPhone 官方 App Store 截图，版本 9.6.30：https://apps.apple.com/cn/app/id590338362
  - 个人主页集中最近、本地和歌单；播放页有直接评论入口，曲目与个人内容有明确层次。
- 参考截图由 Apple lookup API 的真实 screenshotUrls 获取，仅作设计研究，未复制进产品。

采用内容层级和操作方式，不引入山海不具备的订阅、社交、推荐算法或版权曲库。保留桌面已有音源、插件、音视频、本地导入、歌词与实验效果能力。UI/UX 技能的通用营销页建议不适用于本原生播放器，采用系统字体、语义颜色和 iOS 原生导航。

## 统一规范

四个主入口：发现、搜索、资料库、我的。设置与插件从我的进入；音源菜单在发现/搜索可见。主操作触控面积至少 44 点，明暗模式与动态字体，非必要动画尊重减少动态效果。封面卡片、分区标题、错误重试、加载、空态、曲目菜单统一。

发现采用横向精选卡片与紧凑的曲目分组；搜索独立，空白页显示搜索历史及真实分类入口。资料库优先分类、最近添加和歌单；个人页提供账号卡片、平台内容和设置。播放器采用完整舞台、紧凑控制、歌词切换、评论/队列、可见曲目操作。列表页提供播放/随机和明确的更多菜单。设置、插件和网络采用分组表单，破坏性操作确认，异步操作反馈。
