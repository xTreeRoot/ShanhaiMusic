# 远程插件更新、自动分页与动作对齐

iOS Build 25（2026-11-20）。一键导入/覆盖接受 GitHub 仓库地址或公开星标列表；更新统一读取默认分支 HEAD，再按固定 SHA 下载。旧完整 URL 来源会归一化；相同版本号的新提交仍可更新，同一提交跳过。移除独立检测更新按钮和启动时的检查阶段，全部更新直接完成比较与安装。覆盖前核对仓库和插件 ID，新增网络权限单独确认，个别失败不阻止其他插件；账号、设置与停用状态保存在独立目录。

搜索、个人资源、评论和插件列表触底后自动加载，同游标只请求一次，保留失败重试与刷新后的重新分页。播放器四个动作使用一致的图标槽和标题基线。

Swift 行为回归 190 项通过，覆盖远程 SHA 固定、旧来源迁移、同版本不同提交、失败隔离、权限及私有数据保留。iPhone/iPad 通用 Release 构建通过。播放器动作对齐、搜索及个人资源自动分页、插件音乐/视频分页分别连续运行 5 次，结果见本地 PagingFiveRuns.xcresult。截图来自相同分页与对齐实现的首轮成功测试，为隔离演示内容，不代表真实账号内容。

Build 25 已通过局域网无线覆盖安装并启动到 iPhone 15。四个插件的公开运行文件和来源标记逐个复制、读回并核对一致：网易云 0.1.17、汽水 0.4.0、YouTube 0.1.7、喜马拉雅 0.1.7；更新前后插件私有目录文件元数据一致。用户确认 YouTube 发现页已能显示内容。原生 OAuth 遇到公开首页 HTTP 400 时仅公开发现页回退游客请求，账号与个人资料库仍保留原会话；实际个人音乐库行为尚未单独验收。
