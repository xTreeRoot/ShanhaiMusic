# 显式刷新：iOS Build 39 / Android 0.1.37

修复宿主仅清目录缓存、插件仍复用旧首屏的问题。移动端下拉向插件传递可选 `refresh: true`；宿主跳过新鲜缓存，并将成功响应写回原缓存键。YouTube 外部插件 0.2.6 同步替换 Shorts、栏目更多页首屏和续页游标；失败保留旧内容，成功空响应结束旧分页。普通打开“更多”仍使用当前首页的真实首屏。

## 验证

- Swift 206 项行为回归通过，包括插件内部快照、同键缓存替换、首页和独立导航刷新。iPhone/iPad 模拟器测试构建与通用设备 Release 构建通过。
- iPhone、iPad 下拉刷新 UI 各连续五轮通过。初轮测试触点按滚动区域的 8% 计算，实际落入透明顶栏背后；按可见导航栏下方确定触点后，两种设备各连续五轮通过。未修改手势或降低更新断言。
- Android JVM 160 项、lint 与三种 APK 构建通过；4 项刷新/分类设备回归各连续五轮通过。
- YouTube 插件 50 项回归通过，覆盖直接 Shorts、栏目更多、分类父页、失败保留游标、成功空响应、官方序列切换及服务端原标题匹配。
- 真实账号只读验证 Shorts 栏目刷新后内容变化，续页 7 条与新首屏不重复；直接 Shorts 12→16 条；音乐推荐 5→6 条，续页 6 条不重复。没有附带响应、账号或令牌。
- `npm run test:plugins` 通过；桌面生产代码未更改，未重新构建桌面包。

## 真机及资产

iPhone 无线覆盖 Build 39，公开插件文件逐个合并并读回核对为 YouTube 0.2.6。129 个私有文件规范化摘要在 App 和插件更新前后均相同，启动成功。安卓原签名无线覆盖 0.1.37，首次安装时间保持不变；插件通过正常更新入口由用户确认，未读取正式版私有目录。

公开 IPA 已移除个人开发签名及设备描述文件，使用者须自行签名。原始设备备份独立保留。`source-sha256.json` 记录 343 个生产源码与配置摘要；尚未完成的栏目定制功能不在本次发布中。
