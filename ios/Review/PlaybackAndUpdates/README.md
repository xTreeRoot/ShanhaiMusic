普通 DemoSource 的浮窗测试不等同于真实 AVPlayerLayer 的系统画中画验收。真实视频表面生命周期的专项修复与补充记录在独立视频验收目录。

Android 真机从独立备份恢复文件并更新公开插件，原下载音频逐文件核对；之后本地系统安装器覆盖回正式包，首次安装时间保持不变，用户确认资料恢复。备份未包含事故前的 SQLite 数据库，无法据此声称旧数据库全部恢复。iPhone 最新正式包覆盖安装前后 132 个私有文件逐文件核对一致，用户确认视频返回与展开恢复正常。私有备份和登录存储保留在仓库外，不随本目录提交。
