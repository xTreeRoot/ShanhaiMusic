# 山海 Android

此分支是安卓客户端的开发、构建与发布入口。工程位于 `android/`。`ios/` 下仅保留 Gradle、CMake 和设备测试所引用的共享 QuickJS 实现、宿主脚本与测试素材，不包含 iPhone/iPad App 源码。

- [构建与功能说明](android/README.md)
- [功能与验收记录](android/PARITY.md)
- [插件宿主契约](plugins/README.md)

桌面在 `main`，iPhone/iPad 在 `ios` 分支。下载客户端请使用[发布页](https://github.com/xTreeRoot/ShanhaiMusic/releases)。
