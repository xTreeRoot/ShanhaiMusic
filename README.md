# 山海 iPhone / iPad

此分支是 iPhone/iPad 客户端的开发、构建与发布入口。工程位于 `ios/`，另保留 UI 测试引用的共享竖屏视频素材，不包含安卓 App 源码。

- [构建与功能说明](ios/README.md)
- [签名与安装](ios/INSTALL.md)
- [页面截图与验证记录](ios/Review/README.md)
- [插件宿主契约](plugins/README.md)

桌面在 `main`，安卓在 `android` 分支。下载客户端请使用[发布页](https://github.com/xTreeRoot/ShanhaiMusic/releases)。
