# 山海插件宿主

桌面、iOS 和 Android 仅保留通用插件宿主，不编译、嵌入或自动注册任何远程信息源。信息源必须在独立仓库维护，以标准 `plugin.json` 和 JavaScript 入口发布，通过设置中的插件管理安装、更新、停用和移除。没有插件时保留本地资料库和插件管理入口。

[哔哩哔哩插件](https://github.com/xTreeRoot/mygo-music-bilibili) 与社区插件使用同一套安装、能力发现、权限和隔离存储机制。其平台 ID 保持 `bilibili`，已有队列、下载、收藏和插件数据不改名、不清除；源码不再随 App 分发。平台请求与行为测试在独立插件仓库运行。

## 职责边界

- 插件负责平台 API、域名、签名、登录会话、分页、字段解析、媒体地址和字幕转换。不得把这些实现复制到 Go、Swift、Kotlin 或 App 资源中。
- App 负责窗口、队列、解码、播放时间轴、音视频同步、字幕展示、本地文件、资料库、网络权限、插件安装更新和通用错误反馈。
- 平台需要新增交互时，先扩展 `internal/music` 和 `internal/plugin` 及移动端对应协议，再让所有插件按能力使用；不能按平台 ID、类名或域名分支。
- App 数据迁移只处理当前用户的本地旧数据，保留原文件，不覆盖目标已有键，不复制其他程序或设备的账号。平台字段格式由插件转换。
- 插件数据与代码独立保存。更新和移除代码不得删除账号、资料库、下载或设置；已有同 ID 数据在安装外部插件后继续使用。

## 通用扩展

基础宿主兼容版本与山海产品版本独立维护。山海扩展不代表所有上游 MyGo 宿主都已实现。

跨端插件使用一个 `id`、一个清单 `version`、一个 GitHub 发行版本和一份 `plugin-universal.zip`。在该发行版本上传这份同名附件，三端安装和更新优先下载它，不再生成平台专包；没有该附件的旧仓库沿用原安装流程。发行标签与清单版本对应，例如 `v1.2.3` 和 `1.2.3`；已发布的附件不覆盖，修订时发布新版本。

`minAppVersion` 仍是字符串，作为默认宿主门槛。可选 `minAppVersionByPlatform` 可为 `desktop`、`ios`、`android` 分别覆盖门槛；省略的端使用默认值。覆盖值是三段以点分隔的非负十进制整数，每段不超过 `2147483647`。旧宿主忽略覆盖字段，仍按默认门槛检查；新增覆盖不会提高宿主自己的兼容版本，也不会跳过权限检查。

桌面插件入口可以通过相对路径静态导入包内的 `.js`、`.mjs` 和 `.ts` 文件，也可以重新导出包内模块的能力。只解析插件包内的文件，不解析远程地址、裸包名或动态导入。模块与入口共享同一套权限；安装检查会链接模块，但不执行插件代码。模块图最多 256 个源文件、合计 16 MiB。

| 插件导出 / 宿主接口 | 契约 | 宿主行为 |
| --- | --- | --- |
| `video({id, quality, network?})` / `music.VideoSource` | 返回 `{url, headers?, type?, videoQuality?, videoQualities?:[{id,label}]}`，`id` 与音频一致；移动端 `quality` 为 `auto` 或插件返回的画质标识 | 只有支持视频的插件才显示播放入口，音频和视频共用时间轴；画质偏好独立于音乐音质并持久保存，后续视频沿用；资源回退须报告实际画质，不覆盖用户偏好。旧宿主可忽略新增字段；`network` 可提供 `bandwidthBps`（近期有效吞吐）、`constrained`（流量受限）和 `recentStall`（近期缓冲），仅供自动画质选择使用，不得覆盖手动画质 |
| `cancelSignIn()` / `music.SignInCanceler` | 停止当前登录请求、轮询、计时器，挂起调用须结束 | 关闭登录弹窗后取消，忽略迟到响应 |
| `lyrics({id})` | `{lrc, translation}` 或 `{lines:[{start,end,text,words?}]}`，时间为毫秒 | 字幕和歌词按共用播放时间轴显示 |
| `Section.trackLayout: "videos"` | 可选视频卡片网格，保留标准 `tracks` | 统一卡片、封面、时长、作者和队列行为 |
| `host.signInPrompt({qr,text})` | `qr` 可省略，仅更新文字状态 | 共用登录弹窗、二维码与取消操作 |
| `requestHeaders`、媒体 `headers`、`host.storage` | 清单声明域名和请求头，隔离持久化 | 页面不接触平台凭据；媒体按实际响应处理 |

新增能力需有不依赖具体平台的宿主回归。平台真实接口、扫码和权益测试归独立插件仓库，播放器通用行为测试留在 App。

### 授权 CENC 音频（可选）

`host.capabilities.cencAudio === true` 时，`stream()` 可在标准资源上附加 `encryption: { scheme: "cenc", key: "32位十六进制内容密钥" }`，`type` 必须为 `m4a`。密钥必须来自当前账号对该资源的合法授权；平台私有密钥封装、权益校验与取流请求留在插件。旧宿主不得接收需要此能力的资源，插件需保留公开资源兼容路径或明确报告不支持。

首个实现为 iOS Build 47，Android 自 0.1.44 支持：宿主检查插件网络权限与每次重定向，读取最多 16 MiB 的非分片 AAC MP4，在后台处理标准 CENC AES-CTR；支持 8/16 字节 IV、清晰子样本及交错文本轨。未知加密方案、分片容器、错误表格均拒绝。结果保存到独立可回收的播放缓存，播放器及下载使用本地资源；不记录内容密钥，不变更账号、原始下载、时间轴或授权时长。其他宿主未声明此能力时继续旧协议。

## 验证

```sh
npm run test:plugins
CGO_ENABLED=0 go test ./...
go tool mygo vet .
```

发布前核对应用包中没有平台原生适配器或嵌入的信息源脚本。独立插件的发行包必须只包含公开运行文件和许可证，不包含任何账号和本地数据。

### 登录方式选择

可选清单字段 `signInMethods` 为 `{ "id": "方式标识", "label": "按钮名称" }` 数组，最多 16 项，标识唯一。移动宿主在点击登录后展示原生选择界面，选中后调用 `signIn({method: id})`；取消选择不启动插件登录。无此字段继续使用既有 `signIn()` 流程。插件应在新账号完成验证后才替换旧会话，并保留 `cancelSignIn()` 行为。旧宿主可以继续通过既有设置提供兼容入口，忽略此可选字段。

### 退出并清理登录缓存（移动宿主）

“退出并清理缓存”是移动宿主能力，不依赖插件导出。iOS 与 Android 对所有外部插件提供该入口，放在普通退出按钮右侧；用户明确点击后，宿主终止该插件两条执行通道和待完成任务，原子重置本插件 `host.storage`，清理目录响应缓存并使旧账号响应失效。下一次登录重新授权。普通 `signOut()` 仍保留插件现有的退出行为。

清理仅涉及当前插件的宿主存储、执行状态和响应缓存，不删除插件设置、名称、排序、资料库、下载、公开代码或其他插件数据，也不会自动触发。iOS 登录网页继续使用临时网站数据存储。旧宿主使用的可选 `signOutAndClearCache()` 插件导出可继续保留用于兼容；新版移动宿主不调用或依赖它。

### 播放器互动总数（可选）

插件可导出 `interactionSummary({ trackId }) -> { likes?: number, comments?: number }`，返回平台公开的总点赞数、总评论数。计数为非负安全整数，字段缺失或 `null` 表示未知；不能把收藏人数、评论赞数或当前页条数当成总点赞数。移动端播放器独立加载这些计数，失败不阻塞播放；未导出时兼容读取 `comments({trackId, offset:0}).total`，不伪造未知数量。`like({id,on})` 成功后只更新已知点赞数，切歌会取消旧曲目请求。作者入口继续使用曲目 `artists[].id` 和 `artist({id})` 的现有契约。

桌面视频简介使用 `artist({id, offset})` 分页展示作者作品，`offset` 从 `0` 开始。返回 `tracks` 和 `more`，可选 `nextOffset`；未返回 `more` 的插件按单页处理。分页包含过滤项时应明确返回严格递增的 `nextOffset`；请求失败应抛出错误，不应误报为没有作品。

### 目录内分类 Tab（移动端可选）

`home()` / `browse({page, offset})` 可返回顶层 `tabs: [{title, page}]` 与 `selectedTab`。宿主沿用平台 Tab 的单行横滚样式，点击分类在当前目录调用 `browse` 替换内容；点击首页 `selectedTab` 对应的分类则重新调用 `home`，恢复完整首页而不降级为普通目录。切换时保留分类栏，不压入新的导航页面。`page` 是插件自己的不透明路由，宿主不解释平台参数。刷新当前分类先失效目录缓存，再请求该分类；切换期间丢弃旧请求的迟到响应。未返回该字段的旧插件行为保持兼容，桌面宿主目前忽略这个可选展示字段。

`playlist({id, offset})` 和 `search({query, kind, offset})` 从 `offset: 0` 开始，返回当前页以及 `more`；旧插件不返回 `more` 时按单页处理。`more: true` 时可返回严格递增的 `nextOffset`，省略时宿主按响应条目数推进。定长平台分页且有过滤项时，应返回明确的 `nextOffset`，不要用过滤后的条目数推算平台页码。`trackCount` 仅用于显示，不代替终页信号。列表触底和播放临近队尾均可请求同一页，插件不应消费一次性顺序状态。搜索结果的名称应是纯文本，不应携带平台 HTML 高亮标签。

### 导航位置（移动端可选）

清单 `navigation` 项可声明 `placement: "personal"`，移动端将其展示到该插件的“我的内容”，并从发现栏目及其预加载中排除。省略或 `"discovery"` 保持原发现导航行为。`page` 仍通过 `browse` 打开，`builtin` 沿用现有资料库集合方法。个人项与自动生成的同路由账号主页、同集合入口去重，保留清单顺序；未实现的集合不显示。桌面暂忽略这一可选展示位置。

移动端 GitHub 插件确认页展示通用 ZIP 所属的发行说明；沿用源码归档的旧仓库展示下载的固定 SHA 对应的 `commit.message`。缺失时明确提示未提供。网络权限初始折叠，需要时展开审阅。全部更新仍自动安装未新增权限的更新，在结果中展示本轮说明。

### 显式刷新与发现栏目

移动端用户主动下拉刷新时，目录请求会携带可选 `refresh: true`（如 `home({refresh})`、`browse({page, offset: 0, refresh})`）。宿主跳过新鲜缓存并把成功结果写回同一缓存键。插件应同时重新取数据、替换自身首屏快照与续页状态；失败时保留旧数据和游标，成功空响应则清空旧内容并结束分页。旧插件可忽略该字段。

### 通用发现页栏目定制

可选清单字段 `discovery` 是最多 128 个独立栏目声明，格式为 `{ "id": "stable-id", "title": "栏目标题", "page": "opaque-route", "defaultEnabled": true }`；`page` 和 `builtin` 必须且只能提供一个。`builtin` 复用 `playlists`、`liked`、`recent`、`savedAlbums`、`shows` 或 `stations`，`page` 沿用 `browse({page, offset, refresh})`。稳定 ID 不随标题或排列改变。同一清单中的 ID 唯一，格式与插件 ID 相同且不超过 128 字节。标题最多 240 字节，路由最多 4096 字节。

宿主依据本地选择，仅调用开启栏目的独立入口，按用户顺序展示，标题左、更多右。桌面预览固定五列、最多两行十张，不横滑；移动端按可见宽度排列，最多两行横滑。不先执行聚合 `home()` 再过滤结果；关闭栏目不发起其请求或封面预取。刷新保留现有 `refresh: true` 语义，发现页“更多”进入栏目的首屏完整列表；单列表的 `morePage` 由列表触底继续加载；集合栏目进入宿主原有集合页。若服务端一个接口捆绑多种数据，插件可复用该真实响应，但不得为关闭栏目继续请求额外数据。没有声明的旧插件仍兼容聚合首页及其导航，编辑器以这些独立入口为单位控制。

首次使用按 `defaultEnabled`（省略为 true）加载；用户明确保存过栏目选择后，插件后来新增的栏目保持关闭，用户可开启或恢复默认。移除插件不删除其选择；名称、顺序均不作为标识。编辑草稿取消不落盘，保存只更新实际修改的字段，避免覆盖编辑期间到达的节点更新。

栏目偏好使用独立的 `app/discovery` 加密记录，格式为 `{ "version": 1, "plugins": { "plugin-id": <栏目寄存器文档> } }`；每个栏目文档复用插件偏好的 `enabled` 和 `order` 字段及其逻辑时钟，`names` 必须为空。三端各保存两份原子本地快照，单份丢失或损坏时修复；两份均损坏时报告错误，不用默认配置覆盖。启用节点后，在启动、回到前台、绑定变化及本地编辑时主动拉取、合并落盘，然后以 ETag 条件写回。该独立记录避免旧客户端更新 `app/plugins` 时清掉栏目选择。卸载导致本地数据被系统删除时，需要原节点绑定与恢复密钥才能恢复远端副本。

## 插件图标与社区目录

可选清单字段 `icon` 指向插件包内的相对图片路径，推荐至少 120 × 120 的 PNG、JPEG 或 WebP。三端插件管理显示该图标；未声明时使用 GitHub 仓库作者头像或默认图标。绝对路径和包外相对路径不作为图标读取。图标仅用于宿主界面，不新增插件网络或文件权限。

插件中心提供已安装列表、社区搜索和分页安装；社区只展示[山海维护的 GitHub Stars 列表](https://github.com/stars/xTreeRoot/lists/fork-mygo-%E5%B1%B1%E6%B5%B7-%E8%87%AA%E8%A1%8C%E7%BB%B4%E6%8A%A4%E4%BB%93%E5%BA%93-%E5%A4%9A%E5%B9%B3%E5%8F%B0)中的插件，搜索和分页均在该列表内进行。目录项不代表运行兼容性或审核结果，安装继续经过当前端的清单、最低版本、能力和权限检查。安装成功返回已安装并定位高亮，原名称、排序、栏目选择、私有存储与账号数据沿用原机制。一键导入/覆盖入口已移除；节点签名目录继续独立使用，无新增服务端接口。
