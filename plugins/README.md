# 山海插件宿主

桌面、iOS 和 Android 仅保留通用插件宿主，不编译、嵌入或自动注册任何远程信息源。信息源必须在独立仓库维护，以标准 `plugin.json` 和 JavaScript 入口发布，通过设置中的插件管理安装、更新、停用和移除。没有插件时保留本地资料库和插件管理入口。

[哔哩哔哩插件](https://github.com/xTreeRoot/mygo-music-bilibili) 与社区插件使用同一套安装、能力发现、权限和隔离存储机制。其平台 ID 保持 `bilibili`，已有队列、下载、收藏和插件数据不改名、不清除；源码不再随 App 分发。平台请求与行为测试在独立插件仓库运行。

## 职责边界

- 插件负责平台 API、域名、签名、登录会话、分页、字段解析、媒体地址和字幕转换。不得把这些实现复制到 Go、Swift、Kotlin 或 App 资源中。
- App 负责窗口、队列、解码、播放时间轴、音视频同步、字幕展示、本地文件、资料库、网络权限、插件安装更新和通用错误反馈。
- 平台需要新增交互时，先扩展 `internal/music` 和 `internal/plugin` 及移动端对应协议，再让所有插件按能力使用；不能按平台 ID、类名或域名分支。
- App 数据迁移只处理当前用户的本地旧数据，保留原文件，不覆盖目标已有键，不复制其他程序或设备的账号。平台字段格式由插件转换。
- 插件数据与代码独立保存。更新和移除代码不得删除账号、资料库、下载或设置；已有同 ID 数据在安装外部插件后继续使用。

## 通用扩展

基础宿主兼容版本与山海产品版本独立维护。山海扩展不代表所有上游 MyGo 宿主都已实现。

| 插件导出 / 宿主接口 | 契约 | 宿主行为 |
| --- | --- | --- |
| `video({id, quality})` / `music.VideoSource` | 返回 `{url, headers?, type?, videoQuality?, videoQualities?:[{id,label}]}`，`id` 与音频一致；移动端 `quality` 为 `auto` 或插件返回的画质标识 | 只有支持视频的插件才显示播放入口，音频和视频共用时间轴；画质偏好独立于音乐音质并持久保存，后续视频沿用；资源回退须报告实际画质，不覆盖用户偏好。旧宿主可忽略新增字段 |
| `cancelSignIn()` / `music.SignInCanceler` | 停止当前登录请求、轮询、计时器，挂起调用须结束 | 关闭登录弹窗后取消，忽略迟到响应 |
| `lyrics({id})` | `{lrc, translation}` 或 `{lines:[{start,end,text,words?}]}`，时间为毫秒 | 字幕和歌词按共用播放时间轴显示 |
| `Section.trackLayout: "videos"` | 可选视频卡片网格，保留标准 `tracks` | 统一卡片、封面、时长、作者和队列行为 |
| `host.signInPrompt({qr,text})` | `qr` 可省略，仅更新文字状态 | 共用登录弹窗、二维码与取消操作 |
| `requestHeaders`、媒体 `headers`、`host.storage` | 清单声明域名和请求头，隔离持久化 | 页面不接触平台凭据；媒体按实际响应处理 |

新增能力需有不依赖具体平台的宿主回归。平台真实接口、扫码和权益测试归独立插件仓库，播放器通用行为测试留在 App。

## 验证

```sh
npm run test:plugins
CGO_ENABLED=0 go test ./...
go tool mygo vet .
```

发布前核对应用包中没有平台原生适配器或嵌入的信息源脚本。独立插件的发行包必须只包含公开运行文件和许可证，不包含任何账号和本地数据。

### 登录方式选择

可选清单字段 `signInMethods` 为 `{ "id": "方式标识", "label": "按钮名称" }` 数组，最多 16 项，标识唯一。移动宿主在点击登录后展示原生选择界面，选中后调用 `signIn({method: id})`；取消选择不启动插件登录。无此字段继续使用既有 `signIn()` 流程。插件应在新账号完成验证后才替换旧会话，并保留 `cancelSignIn()` 行为。旧宿主可以继续通过既有设置提供兼容入口，忽略此可选字段。

### 播放器互动总数（可选）

插件可导出 `interactionSummary({ trackId }) -> { likes?: number, comments?: number }`，返回平台公开的总点赞数、总评论数。计数为非负安全整数，字段缺失或 `null` 表示未知；不能把收藏人数、评论赞数或当前页条数当成总点赞数。移动端播放器独立加载这些计数，失败不阻塞播放；未导出时兼容读取 `comments({trackId, offset:0}).total`，不伪造未知数量。`like({id,on})` 成功后只更新已知点赞数，切歌会取消旧曲目请求。作者入口继续使用曲目 `artists[].id` 和 `artist({id})` 的现有契约。
